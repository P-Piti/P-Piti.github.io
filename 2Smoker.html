Style: Three files + web fonts. HOW TO RUN 1. Put index.html, styles.css, game.js and the assets/ folder (fonts.css + the type-*.ttf files) in one directory. 2. Open index.html in a browser (or serve the folder with any static file server). Everything is local - no build step. HOW TO PLAY - Hold LEFT CLICK on an orange bolt to unscrew it (hold, don't click). - Use the LOOSEN / TIGHTEN ratchet direction change buttons (top-right of the workbench) or press R to flip direction. Orange bolts loosen, green bolts tighten. - Work order: cylinder head -> base bolts -> piston & gasket -> reassemble & torque -> dyno run & tune. - Performance parts shop, fuel/ignition tune, dyno graph, XP & credits, progress saved to localStorage (key: 2stroke-garage-v1). - Engines: SX 125 TBI · SIMSON S51 · SX 85. Each saves its own progress. FILES IN THIS DOCUMENT 1. index.html - markup, SVG icon sprite, skeleton 2. styles.css - the complete visual design (v1) 3. game.js - all game logic (state, holds, dyno, audio, save) 4. assets/fonts.css - @font-face declarations NOTE ON FONTS assets/type-0.ttf ... type-7.ttf are binary TrueType files and cannot be embedded in a text file. They are kept in the workspace under /home/user/assets/ (SIL Open Font License - see assets/OFL.txt). Without them the game still runs, using fallback fonts.
